## 资料使用规则

- 区分“用户已确认”“本地文件事实”“规划建议”和“待确认”，不把建议当作正式需求。
- 品牌名称、核心卖点、客户案例、业务数字和价格等对外内容必须有实际来源。
- 后续决定及时更新对应文档，并在规划草案的决策记录中登记。
- 代码存在不代表功能已通过运行验证；历史部署记录不代表当前线上状态。
- 文档不保存密码、访问令牌或私有连接凭据。
