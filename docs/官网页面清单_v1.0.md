# 官网页面清单 v1.0

日期：2026-09-28  
依据：[官网内容架构 v1.0](./官网内容架构_v1.0.md) 第 1–7 节  
配套：[官网内容规划 v1.0](./官网内容规划_v1.0.md)  
状态：供确认的页面规划，不代表产品功能已上线或路径已实现。

## 1. 规划口径

- 官网定位：AI 原生 Commerce & Content Operations 平台，连接 Shopify、Strapi 与其他业务渠道。
- 首期叙事：以 Shopify SEO/GEO + Site Health 为切入点，解释从发现问题、审阅建议到执行与复检的流程；Product Knowledge 与多站点治理承接长期价值。
- 正式品牌名、首发客户细分、主语言、产品可用范围仍待确认。英文名称用于页面工作命名，不等于确认英文首发。
- 主 CTA 暂按源文档建议统一为 **Book a Demo**。自助注册、安装、登录入口必须有可用目标后才展示。
- 下表 URL 为规划路径；默认语言、语言前缀及现有路由兼容性在开发准备时确认。
- P0 表示建议首发范围，仍需满足各页上线条件；P1 为有内容与能力支撑后扩展；P2 为依赖商业模式或长期维护的页面。

## 6. 页面生产顺序

1. 先核验品牌、首发客户、功能状态及一个扫描到复检的真实案例。
2. 按源文档优先完成 P01 Home、P03 SEO & GEO、P04 Shopify、P06 How It Works、P08 Security 的文案与线框。原文“Platform”在此具体落到 How It Works。
3. 补齐 P02 Product Overview、P05 Strapi & Multi-site、P07 Integrations，统一能力与集成表述。
4. 完成 P09 Contact 与 P10–P11 的实际流程及正式文本；这些是上线依赖，不因排在后面而降级。
5. 核对导航、锚点、CTA、功能声明和页面元信息后，才进入首发验收。
