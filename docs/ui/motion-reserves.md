# fast2x 局部光感动效预留 v1.1

适用更新：光效规则继续适用于 UI v1.2。新预览的图层 ID 以 [当前 Figma manifest](./figma-manifest.json) 为准；本文件的动效版本仍为 v1.1。

日期：2026-09-28。当前交付为 Figma 独立图层、静态光效对照和实现规格，尚未制作可播放动画或网站代码。

[Figma 光感预留板](https://www.figma.com/design/SBTFhKQLQmPOBY7LbhY05e/prd-web?node-id=87-168)

## 视觉约束

- 页面和区块背景仅使用黑、白、灰；不使用蓝色或其他彩色整块背景。
- 彩色只出现在小面积图形、状态圆点或局部光效中。状态标签的底色与文字保持中性。
- 光只沿物体局部边缘或图形路径出现；不增加全屏光晕、鼠标追光背景或持续闪烁。
- 首屏结构图为概念插画，不表示已上线功能、运行活动或数据状态。

## 图层与触发

| 位置 | Figma 预留 | 触发与时序 | 实现边界 |
| --- | --- | --- | --- |
| 首屏结构图 | `Motion reserve / Hero edge sweep / opacity 0` | 首次进入视口后延迟 200ms，执行一次 1600ms 掠光；不循环 | 中性白色短光段沿顶层前缘移动，透明度 0 → 0.7 → 0 |
| 三个能力图形 | `Motion reserve / Capability trace / opacity 0` | 桌面悬停或键盘焦点进入，180ms 淡入；离开后 240ms 淡出 | 小范围品牌色描边；触屏保持静态。能力面板本身不是链接，不为装饰效果额外增加 Tab 焦点 |
| 主按钮 | 沿用 Action 状态；光泽仅在本规格中预留 | 后续可在真实 hover/focus 状态叠加一次 180ms 轻微光泽 | 裁剪在按钮内部；不替代可见 focus ring，不改变文字对比度或按钮尺寸 |

能力图形的 keyboard focus 规则只在未来面板拥有真实可聚焦操作时启用；当前能力面板没有详情链接，也不增加交互入口。

预留图层在两个设计主稿及两份滚动预览中默认隐藏，每份包含 1 个首屏图层与 3 个能力图层。独立对照板显示 At rest / Edge sweep peak 两个静态状态。节点 ID 见 [manifest](./figma-manifest.json)。

## 效果与开发参数

- `fast2x/Light/Neutral Edge`：白色，28% 阴影透明度，8px 模糊，偏移 0。
- `fast2x/Light/Accent Edge`：品牌蓝，20% 阴影透明度，8px 模糊，偏移 0。
- 高光描边基准宽度 2px；光效透明度应与图层透明度一起计算。
- 使用已有 `cubic-bezier(0.2, 0, 0, 1)` 缓动；以 opacity 和局部 transform 为主，不动画化区块宽高或布局。
- 优先复用 SVG 路径和裁剪范围。首屏只移动短光段，避免整幅插画持续滤镜重绘。
- 离开视口或页面不可见时停止播放；首次进入动画不因来回滚动反复触发。
- `prefers-reduced-motion: reduce`：取消掠光移动及装饰动画，保留静态图形、普通 hover 和 focus ring。
- 动效不参与业务状态判断，不延迟阅读或按钮点击。

## 后续验收

开发后检查桌面、390px 及更窄视口；核验键盘焦点、触屏、减少动态效果、后台暂停和低性能设备。确认没有光效溢出、文字闪烁、布局移动或彩色背景扩散。本轮完成的是设计预留，以上浏览器行为尚未实现或验证。
